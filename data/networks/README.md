# Legacy road-network artifact

`jakarta.net.xml` is a legacy central-Jakarta SUMO network retained for
reference. FleetFlow does not load or serve it. The application routes through
OSRM using the Jakarta-region OpenStreetMap data prepared by
[`scripts/osrm/build-jakarta.ps1`](../../scripts/osrm/build-jakarta.ps1).

The retained file was derived from OpenStreetMap data, © OpenStreetMap
contributors, licensed under ODbL 1.0. Its extent is limited to central Jakarta;
it is not a full-city or metropolitan routing dataset.
